# Open Replay

**Open Replay** هو برنامج Desktop يعمل في الخلفية للاحتفاظ بآخر لحظات من الشاشة، ويتيح للمستخدم حفظها كفيديو بضغطة واحدة.

## المميزات

- **Instant Replay** — احتفظ بآخر 15-300 ثانية من شاشتك تلقائيًا
- **حفظ سريع** — اضغط اختصارًا واحدًا لحفظ اللحظة
- **صوت النظام والميكروفون** — تسجيل صوت النظام والميكروفون معًا أو منفردًا
- **محرر مدمج** — قص البداية والنهاية ومعاينة النتيجة
- **تصدير MP4** — تصدير بجودة عالية مع H.264 و AAC
- **مكتبة مقاطع** — تصفح وبحث وإدارة مقاطعك
- **مؤشر الماوس** — التقاط سلس دون وميض أو تكرار
- **اختصارات عالمية** — تعمل حتى عندما يكون التطبيق في الخلفية
- **عربي وإنجليزي** — واجهة كاملة بالعربية مع دعم RTL
- **تصميم احترافي** — واجهة داكنة مريحة ومصممة للاستخدام اليومي

## متطلبات النظام

- **نظام التشغيل:** Windows 10 (1903+) أو Windows 11
- **المعالج:** معالج 64-bit بتردد 2 GHz أو أعلى
- **الذاكرة:** 8 GB RAM (يُفضل 16 GB)
- **بطاقة الرسومات:** بطاقة تدعم DirectX 11 (يُفضل مع دعم Hardware Encoding)
- **المساحة:** 200 MB للتطبيق + مساحة للمقاطع

## التثبيت والتشغيل

### التطوير

```bash
# تثبيت الاعتماديات
npm install

# تشغيل بيئة التطوير
npm run tauri dev

# بناء نسخة الإنتاج
npm run tauri build
```

### المتطلبات للتطوير

- [Rust](https://rustup.rs/) (stable)
- [Node.js](https://nodejs.org/) (v18+)
- [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) مع C++ desktop development workload
